This project demonstrates a complete AI-powered QA workflow that starts with a User Story and ends with a comprehensive test execution report.

The framework leverages:

- Playwright MCP for browser-based application interaction and exploration.
- Custom AI Agents for test planning, test generation, and test healing.
- Automated Test Planning directly from User Stories and Acceptance Criteria.
- Exploratory Testing using Playwright browser tools.
- Automated Playwright Test Generation based on validated test scenarios.
- Self-Healing Test Workflows to automatically identify and fix test failures.
- Automated Test Execution Reporting and Coverage Analysis.

## Workflow

User Story
→ Test Planning Agent
→ Exploratory Testing
→ Automated Test Generation
→ Test Execution
→ Self-Healing Test Recovery
→ Comprehensive Test Report

## Key Features

- AI-Driven Test Planning
- Playwright MCP Integration
- Exploratory Testing Support
- Playwright TypeScript Test Automation
- Self-Healing Test Framework
- Acceptance Criteria Coverage Tracking
- Automated Reporting and Documentation
- GitHub Actions CI/CD Integration

This repository serves as a practical example of how AI agents can streamline the entire software testing lifecycle, improving test coverage, reducing manual effort, and accelerating delivery quality.
